Developer manual

Use Paged.js to lay out HTML, then author a searchable PDF from that exact paginated DOM with jsPDF. Everything runs locally in the browser and no page screenshot is taken.

01 · Start here

Installation

The npm package is intended for browser applications and bundlers. Node.js can install and bundle it, but conversion requires a browser DOM. 

npm install paged-pdf-js

Importing the module does not access the DOM. The browser is only required when you call a conversion or download function.

02 · First document

Quick start

import { downloadPdf, htmlToPdf } from "paged-pdf-js";

const result = await htmlToPdf(
  `<article>
    <h1>Quarterly report</h1>
    <p>This text remains selectable.</p>
  </article>`,
  {
    styleText: `
      @page {
        size: A4;
        margin: 20mm;

        @bottom-center {
          content: counter(page) " / " counter(pages);
        }
      }
    `,
    metadata: {
      title: "Quarterly report",
      author: "Example team"
    }
  }
);

downloadPdf(result.blob, "quarterly-report.pdf");

The result contains bytes, blob, and pageCount. You can display the Blob in an iframe, upload it, or pass it to downloadPdf.

04 · Public surface

API reference

htmlToPdf(input, options?)

Accepts an HTML string, Element, or DocumentFragment. Input is cloned, sanitized, paginated in an isolated temporary render host, and converted into PDF drawing primitives.

pagedDomToPdf(root, options?)

Converts an existing trusted Paged.js preview containing .pagedjs_page elements. Use this lower-level API when your application already owns the pagination lifecycle.

downloadPdf(bytesOrBlob, filename?)

Starts a browser download and revokes its temporary object URL after use. 

interface PdfResult {
  readonly bytes: Uint8Array;
  readonly pageCount: number;
  readonly blob: Blob;
}

05 · Configuration

Conversion options

Option Purpose
styleText Self-contained CSS and Paged Media rules.
baseUrl Base URL used to resolve relative image and link URLs.
allowedResourceOrigins Explicit cross-origin PNG/JPEG allowlist.
renderMode vector (default), hybrid for raster visuals with selectable text and links, or raster.
metadata PDF title, author, subject, and keywords.
signal AbortSignal for cancelling expensive conversion.
onProgress Receives paginate, assets, render, and write phases.

Cancellation and progress

const controller = new AbortController();

const result = await htmlToPdf(html, {
  signal: controller.signal,
  onProgress(progress) {
    console.log(progress.phase, progress.page, progress.totalPages);
  }
});

06 · Failure handling

Errors

Conversion failures are PagedPdfError instances with stable machine-readable codes.

Code Meaning
BROWSER_REQUIRED The conversion API was called without a browser DOM.
INVALID_INPUT HTML, resource, size, or safety validation failed.
PAGINATION_FAILED Paged.js could not produce a valid page DOM.
PDF_WRITE_FAILED PDF primitive authoring or serialization failed.
ABORTED The caller cancelled the conversion.

07 · Boundaries

Security and limitations

Conversion happens locally. High-level string and element input is cloned and active HTML is removed before pagination. Remote images are same-origin by default and cross-origin PNG/JPEG files require both an explicit allowlist entry and suitable CORS headers.

  • External stylesheets, CSS @import, scripts, frames, SVG execution, and responsive srcset loading are blocked.
  • Use trusted input where possible and retain an application-level sanitizer for untrusted authoring workflows.
  • The vector renderer supports text, solid fills and borders, PNG/JPEG images, and links. It omits gradients, shadows, transforms, complex scripts, custom-font embedding, and tagged PDF structure.
  • Input, DOM, page, command, image, timeout, and output limits protect the browser from unbounded work.
